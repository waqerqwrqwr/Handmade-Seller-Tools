# Simple Tool Works — Final Website Package

This is the final overlay package for `simpletoolworks.com`.

## Included
- index.html
- demo.html — Free Tools index
- 10 calculator pages
- pro-excel.html
- about.html / contact.html / privacy.html / terms.html
- styles.css
- robots.txt
- sitemap.xml

## Important
The package intentionally does NOT include `product.html` or `blog/` as active site pages. Do not restore links to those old paths.

Your existing `images/` folder should be kept because the pages reference:
- images/dashboard.png
- images/pricing-calculator.png
- images/product-database.png
- images/wholesale-calculator.png

## GitHub upload
1. Back up the current repository.
2. Upload/replace the files in this package.
3. Keep the existing `images/` folder.
4. If the old `product.html` and `blog/` are still in the repository, they can be deleted after confirming no needed content remains.
5. Commit all changes once.
6. Wait for Cloudflare Pages deployment.
7. Test `/`, `/demo.html`, all 10 calculator URLs, `/pro-excel.html`, and legal pages.
8. Then submit the sitemap in Google Search Console.

## Calculator design
All calculators use editable assumptions and do not claim to be official marketplace calculators. Etsy fee-related pages intentionally avoid hard-coding a claim about current platform fees.
